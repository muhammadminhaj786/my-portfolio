# Muhammad Minhaj | Portfolio

Personal site. Next.js 16, Tailwind CSS v4, React Three Fiber, GSAP and Lenis.

```bash
npm install
npm run dev
```

Content is in `src/data/portfolio.ts`. The 3D scene lives in `src/components/three/`, and its per-section poses are in `src/components/ScrollChoreography.tsx`.

Set `NEXT_PUBLIC_SITE_URL` in production so OG tags and the sitemap use the real domain.
